# `platform` Terraform module

Composes the notification, logging, IAM, response-action, orchestration, investigation, and event-routing modules into one deployable platform.

This module is part of `v2.6.0 — Deployment Modules`. Prefer the top-level [`platform`](../platform/README.md) module unless you have a reason to compose service modules separately. High-impact behavior remains governed by the automation safety model.

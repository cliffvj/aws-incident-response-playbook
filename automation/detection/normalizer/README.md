# Detection event normalizer

This Lambda receives selected Amazon EventBridge security and operational events, converts them into a small normalized incident envelope, suppresses duplicates, and routes them either to **notify-only** handling or the existing **read-only Step Functions triage path**.

It deliberately does **not** start live containment in `v2.5.0`.

## Supported inputs

- Amazon GuardDuty `GuardDuty Finding`
- AWS Security Hub CSPM `Security Hub Findings - Imported`
- AWS Config `Config Rules Compliance Change`
- Amazon CloudWatch `CloudWatch Alarm State Change`
- selected `AWS API Call via CloudTrail` events
- `aws-ir.lab / Simulated Security Finding` for the later authorized capstone lab

## Safety controls

- `DEFAULT_RESPONSE_ROUTE` is `notify_only` unless deliberately changed to `triage`.
- `triage` is accepted only when an EC2 instance can be extracted and always invokes the workflow with `dry_run: true`.
- `ALLOWED_ACCOUNT_IDS` can constrain source accounts.
- `IGNORE_PRINCIPAL_ARN_PREFIXES` suppresses CloudTrail events generated by known automation principals.
- DynamoDB conditional writes provide time-bounded duplicate suppression.
- Raw findings are not copied into workflow inputs. A SHA-256 digest is retained for correlation instead.

## Environment variables

| Variable | Required | Default | Purpose |
|---|---:|---|---|
| `DEDUP_TABLE_NAME` | Yes | — | DynamoDB table keyed by `dedupe_key`. |
| `STATE_MACHINE_ARN` | Yes for triage | — | EC2 incident-response Standard Workflow. |
| `INCIDENT_TOPIC_ARN` | Yes for notify | — | KMS-encrypted responder SNS topic. |
| `DEFAULT_RESPONSE_ROUTE` | No | `notify_only` | `notify_only` or read-only `triage`. |
| `DEDUP_TTL_SECONDS` | No | `86400` | Duplicate suppression window. |
| `ALLOWED_ACCOUNT_IDS` | No | empty | Comma-separated source-account allowlist. |
| `IGNORE_PRINCIPAL_ARN_PREFIXES` | No | empty | Comma-separated principal ARN prefixes ignored for loop prevention. |

# v2.2.0 — Response Actions

Phase 3 Commit 2 expands the dry-run-first automation framework into a reversible response-action catalog for EC2, IAM, EBS, S3, and SNS workflows.

## Highlights

- Eleven independently deployable Python Lambda response actions
- S3 public-access inspection, containment, and restoration
- Per-incident quarantine security-group creation or reuse
- Multi-interface EC2 isolation and manifest-based restoration
- IAM access-key ownership validation, disablement, and restoration
- EBS snapshot duplicate prevention and richer incident tagging
- Checksummed rollback manifests with account, Region, incident, and resource validation
- State-based idempotency with explicit `no_change` results
- Expanded least-privilege IAM examples and Terraform deployment scopes
- Machine-readable action catalog and contract validation
- Thirty-one mocked unit tests
- Runbook-to-automation cross-references and complete operator documentation

## Safety model

- Every mutating action defaults to `dry_run: true`.
- Restoration requires `confirm_restore: true` and a valid matching rollback manifest.
- Cross-account and cross-Region mismatches fail closed.
- S3 containment modifies only bucket-level Block Public Access; policy and ACL documents are captured but left unchanged.
- Quarantine security groups must have no ingress or egress rules.
- Automatic detection triggers remain intentionally out of scope until later Phase 3 commits.

## Upgrade notes

- The EC2 isolation function now modifies security groups per attached network interface and requires `ec2:ModifyNetworkInterfaceAttribute` rather than `ec2:ModifyInstanceAttribute`.
- IAM disablement now requires `iam:ListAccessKeys` to verify the supplied user/key pair.
- EBS snapshot idempotency requires `ec2:DescribeSnapshots`.
- Terraform users should copy the updated `terraform.tfvars.example` and configure authorized `s3_bucket_arns` and `iam_user_arns` before live tests.
- Preserve complete Lambda output objects because rollback actions require the exact returned manifest.

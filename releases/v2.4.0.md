# v2.4.0 — SSM Investigation

Phase 3 Commit 4 adds a controlled host-evidence plane built on **AWS Systems Manager Automation and Run Command**. The release focuses on retrieving useful host metadata without opening inbound SSH/RDP and without coupling investigation to containment or remediation.

## Highlights

- Read-only Linux and Windows Automation documents
- Managed-node `Online` and platform preflight
- Processes, network state, services, packages/software, users/logons, scheduled tasks, and bounded selected logs
- Incident-specific S3 prefixes using Automation execution IDs
- Versioned evidence bucket with Block Public Access and default SSE-KMS
- Dedicated rotating KMS key and configurable lifecycle retention
- Per-object SHA-256 integrity manifest
- Local manifest verifier
- Separate Automation, managed-node write, and responder read/start permission sets
- Terraform deployment and outputs
- SSM document validator, unit tests, samples, architecture diagram, troubleshooting, retention, and platform-boundary guidance

## Safety boundaries

The collection documents do **not** quarantine instances, stop services, patch hosts, delete files, alter security groups, dump credentials, or collect memory. They abort before Run Command when the instance is not returned by Systems Manager, is not `Online`, or does not match the expected operating system.

Linux is the primary authorized-lab validation target for this release. Windows is included as a read-only reference implementation and should be validated in the same dedicated account before broader use. macOS is intentionally out of scope.

## Evidence integrity

Run Command stores stdout/stderr under:

```text
s3://<bucket>/incidents/<incident-id>/<instance-id>/<automation-execution-id>/<platform>/
```

After Run Command completes, an Automation `aws:executeScript` step reads every output object, computes SHA-256, and writes `integrity-manifest.json` with timestamps and correlation identifiers. The local verifier can independently re-read those objects and confirm the digests.

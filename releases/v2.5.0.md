# v2.5.0 — Detection-to-Response

Phase 3 Commit 5 connects selected AWS-native detections to the response automation framework through Amazon EventBridge.

## Highlights

- GuardDuty, Security Hub CSPM, AWS Config, CloudWatch, and selected CloudTrail patterns.
- Event normalization with minimal incident context and source-event SHA-256 correlation.
- Time-bounded duplicate suppression and narrow loop-prevention controls.
- Notify-only by default; optional automatic read-only EC2 triage.
- EventBridge target retries, SQS DLQ, optional archive/replay, samples, tests, and Terraform deployment.

## Safety

This release does **not** automatically start live containment. Detection is an input to response, not proof that a destructive action is justified. High-impact actions remain behind the existing approval boundary.

Phase 3 Commit 6 productionizes Terraform into reusable deployment modules and documents controlled multi-account patterns.

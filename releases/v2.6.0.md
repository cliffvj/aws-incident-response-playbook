# v2.6.0 — Deployment Modules

Phase 3 Commit 6 productionizes the infrastructure layer into reusable Terraform modules.

## Highlights

- Modular KMS/SNS, logging, IAM, Lambda response actions, orchestration, SSM investigation, and EventBridge routing.
- One composed `platform` module for the supported reference deployment.
- Lab, development, and controlled-production adaptation examples.
- AWS Organizations event-forwarding pattern without silently granting cross-account remediation.
- State migration, remote-state example, permissions boundaries, upgrade/rollback/teardown guidance, and CI security checks.

## Upgrade note

Existing v2.5.0 Terraform users must review `automation/terraform/docs/state-management.md` and the generated plan. `moved.tf` maps known resource addresses into the new module tree.
